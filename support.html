Customer support

Find help with the K-Counter ordering demo below.

K-Counter is a front-end demonstration. Orders and support requests are not sent to a restaurant or support team. If you have a real order issue, contact the restaurant or ordering service you used directly.

Common questions

Was my order placed?

No. The order form only displays a sample confirmation in your browser. It does not send an order to a restaurant.

Can I pay digitally here?

You can select a digital payment option to see how the interface works, but this demo does not accept or process payments.

What if I need help with the menu?

Return to the K-Counter home page to review the available menu examples. Prices and items are illustrative and may not match a real restaurant menu.

Try the support form

This sample form demonstrates a support request interface. It does not transmit or save the information you enter.
